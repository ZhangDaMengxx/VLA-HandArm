## 问题

08-07 换用官方灵巧手 URDF（`urdf_right_2025_4_18`）后，法兰与手的装配出现偏移（"圆心偏离"）。

## 根本原因

新旧手 URDF 的 `base` 坐标系约定不同：
- **旧（dex-urdf）**：`base → hand_base_link` joint origin `rpy="-1.57079 0 3.14159"`
- **新（官方）**：同 joint `rpy="0 0 0"`

这个旋转差 **R = Rz(π) @ Rx(-π/2)** 就是两个 base 系之间的坐标变换。08-07 换手时没同步更新法兰→手的挂接量，导致装配姿态错位。

## 修复内容

### 1. 更新主构建脚本

**文件**：`sim/build_nero_inspire.py`

**改动**：第 50-54 行

```python
# 旧值（for dex-urdf 手）
MOUNT_RPY = "0 0 1.570796"

# 新值（for 官方 inspire 手）
MOUNT_RPY = "-1.570790 -0.000000 -1.570799"
```

`MOUNT_XYZ` 保持 `"0.000042 0.005962 0.002158"` 不变（变换纯旋转）。

## 数学推导

```
T_flange_newbase = T_flange_oldbase @ T_oldbase_newbase

其中：
T_oldbase_newbase = (R, 0)  # 旋转 + 零平移（joint origin xyz 都是 0）
R = Rz(π) @ Rx(-π/2) = [[-1, 0,  0],
                         [ 0, 0, -1],
                         [ 0,-1,  0]]

新 MOUNT_RPY = (-1.570790, -0.000000, -1.570799) rad
            ≈ (-π/2, 0, -π/2)
```

## 技术细节

- 坐标系变换矩阵 R 是自身逆（R = R^T = R^{-1}），属对合变换
- 新手 base→hand_base_link joint origin rpy=0 简化了后续维护
- 官方手内部关节约定与 dex-urdf 不同（指关节系也换了），但不影响基座挂接
- ICP 验证失败（6.9mm）属正常：装配体 STL 用旧手做的，新手网格不同源
