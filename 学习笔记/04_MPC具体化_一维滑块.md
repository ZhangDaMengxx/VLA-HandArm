## 1. 为什么先用一维滑块

七轴+雅可比太吵,看不清 MPC 结构。换成:
**一个滑块,光滑直线上,我只能推它(给加速度 a),想让它停在目标点。**

**状态 = [p, v]**(位置 + 速度)。
→ 就是上节课说的"状态必须带速度才有惯性"。也就是 RL 里的环境状态 s。

---

## 2. 世界规律(动力学链条)—— 我自己推的,踩了个坑

我推 f(s,a) 时写了 `v=a·dt`、`x=v·dt`,**只写了"变化量",漏了"在旧值上叠加"**。
补上那半截才对:

```
v[k+1] = v[k] + a[k]·dt      新速度 = 旧速度 + 这帧加的
p[k+1] = p[k] + v[k]·dt      新位置 = 旧位置 + 按当前速度走的
```

**盯着看冒出来的东西**:p[k+1] 拽着 v[k],v[k+1] 拽着 a[k]
→ 每帧状态从上一帧"长"出来,一环扣一环。
→ 这条链子 = 上节课说的"未来N步互相牵连"的**真身**。

**推一下影响是永久的**(我这也想错过一次):
只在第0帧推一下(a[0]=1,之后全0),位置竟一路涨 0→0→1→2→3→4 永远涨。
因为 a 把速度顶到 v=1(第一层积分),没摩擦速度不消失,每帧把位置往前拱(第二层积分)。
→ 不是"a不变位置就不动";恰恰相反,**只要还有速度位置就一直动**,除非反推把 v 归零。
→ 这就是刹车问题的物理老家:想停就不能等到跟前才刹,得提前几帧反推 → 得往前看 → MPC。

**"停下" = 两条,不是一条**(a=0 ≠ v=0):
```
p[N] → 目标点     位置到位
v[N] → 0          且速度归零  ← 少这条,冲到点上也滑过去
```

## 3. 拼成一个大 QP(优化三件套填实)

```
决策变量:  a[0..N-1]                     我能挑的:未来N帧推力

目标函数(越小越好,对未来每帧 k 都加起来 —— 不是只看当前帧!):
   min  Σ w_p·(p[k]−p目标)²      位置到位
      + Σ w_v·(v[k]−0)²          速度归零(=刹车)
      + Σ w_a·a[k]²              别猛推(正则,=第02课DLS里那个阻尼λ‖Δq‖²同角色)

约束(硬,不许违反):
   物理链条(等式): v[k+1]=v[k]+a·dt , p[k+1]=p[k]+v·dt   焊死,不许瞬移
   力上限(不等式): |a[k]| ≤ a_max                        电机就这么大劲
   限位(可选):     p_min ≤ p[k] ≤ p_max
```

**v=0 硬约束 vs 软目标(我无意中两种都想到了):**
- 焊成硬约束 → 保证精确停死,但可能力不够→无解。
- 塞进目标函数当 (v−0)² → 软,永远有解、更皮实,可能差一点点(叫 terminal cost)。
- 真实 MPC 多用软的图鲁棒。

**还是不是碗?自己验:**
- 目标函数全是平方和 → 二次开口朝上 → 碗 ✓
- 约束里 p,v,a 全是一次方 → 线性 → 直墙 → 圈出凸块(没月牙缺口)✓
→ **二次目标 + 线性约束 = QP = 凸 = 实时能解。**
→ **MPC 就是个更大号的 QP**!没学新求解器,只是把第02课"一步的碗"撑成"N步的碗"。

## 4. 碗 vs 围栏 —— 我来回黏了几次,钉死

约束**不是**碗,**不是**"往碗里加个常量",**不是**"碗的值域"。地上两样不同东西:
```
地形(碗)  = 目标函数。给每点标"高度"=有多差。   问:这点多好?
围栏(约束) = 限制。圈一圈栅栏"只准站栏里"。       问:这点能站吗?(是/否)
```
会撞车:碗最深的点可能在栏外(要求力超上限,做不到)→ 只能"栏里头找最低点"。
带约束QP干的就是:**合法范围内,最好的那个。**

**直墙才凸**:线性约束=直墙→圈出凸块;非线性(带p²)=弯墙→往里拱出月牙缺口→非凸。
判据(第02课):凸=区域内任意两点连线还在区域里。直墙圈的地连线不出界→凸。

**间接相关(我自己挖到的宝,也是刹车问题的数学老根):**
`|a|≤a_max` 直接圈在加速度上,但通过链子 v[k+1]=v[k]+a·dt **间接**限死"速度一帧最多改多少"。
→ **没法瞬间把速度打到0** = 刹车问题本身!
→ 要是力无限大(拆了这道栏),就能瞬间刹停、根本不用往前看,MPC 也没存在必要了。
→ **正是这道栏,逼出了"提前看N步"。**

## 5. 真跑对照(sim/mpc_block_1d.py,同一条物理链子,唯一区别=看几步)

目标 p=1.0, v=0, 力上限 |a|≤1.0, MPC 看 N=20 步。

**贪心(只看1步):灾难**
- 前14帧"离目标远就全力冲",速度飙到1.4,过点才猛刹→刹不住→滑到1.96(冲过快一倍)→震荡。
- 最终 p=1.18, v=−1.2, **过冲180mm 还在晃**。

**MPC(看未来20步):优雅**
- 冲到第6帧(速度才0.6)就松手;**第7帧位置才0.28、离目标老远就开始反推刹车**。
  为什么这么早?它往前看20步,算出"再冲力上限那道栏刹不住",所以现在就收。
- 反推力平滑变小(−0.48→−0.05),像老司机点刹。最终 p=0.97, v=0.03, **误差30mm 不过冲**。

```
贪心: 远→猛冲→过点才刹→刹不住→过冲180mm、震荡
MPC:  远远预判刹不住→位置0.28就提前松手反推→平滑点刹→稳停不过冲
```
**区别不在求解器、不在物理(同一条链子),只在"解未来20步一起" vs "只解下一步"。**
