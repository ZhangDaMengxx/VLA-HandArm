## 已知限制

1. **手势执行**: 简化实现，需要完整 backend 逻辑
2. **机械臂**: 占位接口，等待真实实现
3. **Docker**: 环境未就绪，待测
4. **Streamable HTTP**: 未实现（用基础 HTTP）
5. **鉴权**: MVP 无鉴权（局域网假设）
6. **并发**: 无队列控制
